# 常驻 Unity Runtime Prefab

- 保留现有 SDK、Settings、C ABI 和异步 latest-frame 推理。新游戏可显式创建常驻根 Prefab；重复创建不会打开第二路输入，卸载等待原有退役流程。
- 不从旧 Demo 的插值画面反推游戏数据：只在适配器成功接收输入时留一份有租约的原始颜色副本，记录原发布 ID 和真正送给 Runtime 的 ID。按 Runtime ID 与来源/代次严格匹配；没有副本、未完成或结果过期时不发布。
- Prefab 内用独立正交相机定义坐标与离屏目标，更新池化关节点/骨线对象，由同一组坐标批量绘制。游戏从该组件读取同一批关节、源纹理及合成纹理。实时预览另有明确 API，不声称与骨骼同帧。
- 先验证包内 Prefab 的场景卸载和去重合同，再验证像素/坐标一致、空结果、重启及释放。运行 Windows Unity 测试和包/接口边界检查；物理设备验收由用户完成。
