# 识别前后处理增量优化与单包验证

目标：2026-10-12 RK3588 实测前，将已有可验证优化和回退收进同一包；保持单实例，
不改公共 ABI、模型权重、坐标、阈值、稳定身份或真实结果计数。既有 GPU 快照、
模型尺寸回读、RKNN 内存/缓存候选、固定图候选与视频缓存仍保留。

## 本轮新增实现

1. `runtime/common/finite_tensor.h`：ARM64 NEON 四值并行检查指数位，完整检查
   包括背景候选的所有值；拒绝 Inf/NaN，不因跳过低分候选而遗漏损坏张量。
2. `rknn_native_output.h`：密集 FP16 输出用 ARM64 扩展转换；半精度次正规数
   用整数 NEON 处理，保留正负零，不受 FPCR flush/rounding 影响。未知/有填充
   输出布局仍拒绝进入该适配器。第一版全整数向量化实测更慢，已淘汰。
3. `rknn_native_input.h`：已查询的三通道布局直接覆盖 RGB，只清零行尾与分配
   尾部；额外通道布局保留原处理，避免猜测 RKNN 的原生排列。
4. `yolo_decoder.cpp`：明显低于置信度阈值的背景 logit 先排除，省去大量 exp；
   临界区继续走原来的 sigmoid/float 舍入与 0.25 判断。NMS、坐标、排序不变。
5. `rknn_input_qualification.h`：整块位比较替代逐个 float 的 memcmp；相同后
   检查一份有限值即可。仍检查每个值、正负零与 NaN，不放宽候选数值资格。

- architecture guard（包含 public surface 检查）通过。
- OnePlus ARM64 探针：65,536 位型、四种 FPCR rounding 加 flush 标志、未对齐
  输入、四值向量尾部、每个错误位置、填充与哨兵，以及原始真实七人输出对照。
  输出逐位相同；探针不执行模型，不能代表 RK3588 NPU 性能。
