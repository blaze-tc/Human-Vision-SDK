# preview.14 RTSP 选流与独立识别输入

SDK `0.4.0-preview.14` 配套 Input `0.1.0-preview.7`。Runtime Prefab Acceptance 启用同通道 H.264 选流，预览限制为 `1920×1080`。Android GPU/NPU 的 `512×288` 模型可直接使用解码帧生成的独立识别纹理。两路保留同一帧身份，预览可等比缩放，识别提交可以先于同帧预览。旧配置默认采用已有输入方式。

SDK Settings 由帧桥在绘制前选择实际预览纹理；有有效配对时一起显示图像和骨骼，缺少配对时保留实时预览。识别结果供业务独立读取。保存设置会保留选流和模型尺寸分路选项。

## 发布候选验证

- Windows Input 55/55 通过，包含保留未完成纹理的租约、分路交接和 H.264 几何读取。Android ARM64/API26 构建、原生依赖和原有导出核对通过。
- Unity 2021.3.45f1 的 Editor 与 Android 参考程序集编译通过。选流与输出尺寸 18/18。两个离线包按顺序导入独立项目，Runtime Prefab Acceptance 场景可导入。
- 团结编辑器的设置、选流与输出尺寸 EditMode 47/47。使用本地 Exercise-8 RTSP 的 Runtime Prefab PlayMode 2/2，覆盖可见骨骼像素、同帧预览、停启和换代。
- 公开包校验 678 个文件、367 个 GUID、8 个 Android SO、9 个 Windows DLL。15 项打包回归及架构、组件目录和 V1 接口检查通过。

## 独立验收 Demo 的设备证据

此前的统一测试 APK 在一加 9 Pro 使用 H.264 25 FPS 本地回放和 NCNN Vulkan 低档。1080p 与仅有 4K 各测 180 秒，表中为最后一分钟的中位数。

| 选中输入 | 解码 | 预览 | 识别输入 FPS | 同帧可见骨骼 FPS |
| --- | --- | --- | ---: | ---: |
| 1080p 第三流 | 1920×1080 | 1920×1080 | 24.64 | 24.66 |
| 4K 主码流兜底 | 3840×2160 | 1920×1080 | 20.70 | 20.67 |

另短测选中 `1280×720` 和 `720×576`，保持各自预览尺寸。该证据来自移植前的独立验收 APK。公开包的 Android RKNN 模型、厂商运行库和完整私有 APK 按本地资源范围交付。当前公开包尚无 RK3588 热机或游戏动作实测结论。
