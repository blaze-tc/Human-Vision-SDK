# Human Vision SDK 0.4.1 变更与验证范围

SDK **0.4.1** 和 Input **0.1.1** 使用同一 Git 标签 `v0.4.1`。先安装 Input，再安装 SDK。Unity 支持范围为 2021.3+、Windows x64 和 Android ARM64/API 26+。

## Android 启动保护

- Android Input 原图桥进入 Vulkan 前验证实例、物理设备、逻辑设备、图形队列、loader 入口和导入的 Unity 目标图像。设备重置及退出切换设备代次，旧代次资源有明确的失效和延迟回调引用管理。
- 独立模式下关闭预览会跳过 Android 原图桥。启用预览时，图像桥故障通过 `PreviewError` 报告，输入与分析状态使用其各自的诊断字段。
- RK3588 启动 A/B/C 探针使用同一 Neural/Low 配置对照独立原图、独立关闭预览、兼容原图。现场启动故障根因和修复效果仍需同一台 RK3588 的冷启动、重启及崩溃堆栈验证。[启动保护验证](2026-11-24-rk3588-npu-startup-regression.md)

## Runtime Prefab Acceptance

UGUI、输入与识别设置弹窗、EventSystem、骨骼相机和点线保存在场景中，控制器通过 Inspector 引用。左侧切换 RTSP 或本地相机、设置后端与模型、查看状态并采集日志，右侧显示一个原图预览和骨骼。普通骨骼在每次 `Update` 直接读 SDK 有效坐标。成功连接后保存在本机，下次可复用。

日志按钮生成 JSONL 快照，并显示和复制路径。温度从设备所能提供的传感器取得，缺测显示「不可读」。[Demo 和 API 使用说明](../user-guide/UNITY_RUNTIME_PREFAB.md)

## 已测设备性能

一加 9 Pro（LE2120）使用同一 1080p30 RTSP 回放，开启实时预览和骨骼，Unity 目标 30 FPS。两个 APK 均实际使用 `backend.ncnn.vulkan` 低档，首个有效样本后预热 10 秒，各采集 45 秒，纳入 43 个完整 Unity 诊断窗口。对照为场景引用固化前的 UGUI 候选。设备 APK 使用本地资源，以下数据对应这一特定构建。

| 指标 | 对照 APK | 当前 Demo APK |
| --- | ---: | ---: |
| RTSP 解码 / 原生预览发布 FPS | 30.01 / 29.98 | 29.99 / 29.99 |
| Unity 预览纹理平均 FPS | 24.36 | 23.81 |
| Unity 预览最低一秒 FPS | 22.00 | 16.99 |
| 原生推理完成 FPS | 25.70 | 26.68 |
| Unity 有效骨骼 FPS | 25.70 | 26.56 |
| Unity 游戏循环 FPS | 30.01 | 30.02 |
| 解码到有效骨骼结果 p95 | 96.03 ms | 97.92 ms |

两版预览纹理为 1920×1080，SDK 分析输入为 512×288。两轮均无整秒预览零更新、SDK 错误或崩溃记录，43 个窗口均有骨骼点和线绘制计数。原生预览发布稳定在约 30 FPS，Unity 纹理仍有短时更新不足，具体环节待定位。当前版采样最高 CPU 温度 57.9 °C，电池由 26.6 °C 升至 28.2 °C，GPU 和 NPU 温度未获取。短时对照只说明在该设备和设置下的行为。

## 部署与能力边界

原生独立输入当前覆盖 RTSP。Android 图像路径仍用 Vulkan，RGA 未实现。WebCamTexture、VideoPlayer 使用 Unity 兼容输入。独立线程仍共享设备的 GPU、带宽、功耗和散热预算。RK3588 NPU、长时热稳定及跨栏王宿主负载需要单独验收。

公共 Android SDK 采用 RKNN-OFF 构建。配套的私有 SDK、独立 CPU ONNX、RKNN 模型、厂商运行库、真机 APK 和测试视频由本地交付。公共发布保留模型原有许可证、分发及评估资格。[本地 Android 资源部署](../user-guide/LOCAL_ANDROID_CPU_YOLO.md)
