# v0.4.0-preview.16 Android RTSP 高清预览验证

SDK 0.4.0-preview.16 / Input 0.1.0-preview.9。Android RTSP 分路在两个输出槽均可用时，用一次 Vulkan 提交从同一解码帧生成高清预览和低档 512×288 识别输入。任一分路无空槽时，另一分路仍可发布。Runtime Prefab 样例使用相机纹理绘制高清同帧画面。RTSP 重连、来源或配置变化都会清除旧配对。

## 一加 9 Pro 对照

发布基线和最终本地 APK 均使用 Android 14、NCNN Vulkan 低档、同一 1080p H.264 RTSP 素材和 30 FPS Unity 目标。基线和最终 APK 的系统热状态均为 0，电池起点分别为 32.0°C 和 40.0°C。数据来自各自就绪后约 30 秒的短窗口。

| 指标 | preview.15 | 最终候选 |
| --- | ---: | ---: |
| 原生高清转换 FPS | 20.48 | 29.18 |
| Unity 实际观察到的高清帧 FPS | 18.35 | 26.32 |
| 原生分析发布 FPS | 29.10 | 29.28 |
| 512×288 输入的新结果 FPS | 23.89 | 23.34 |
| 高清同帧配对 FPS | 17.09 | 23.23 |

最终候选稳态窗口有 670/673 个有效结果完成高清配对，670 个配对的输入身份核验全部通过。实时预览、同帧底图和合成纹理为 1920×1080。断流并切为 1280×720 后，新连接恢复对应尺寸的预览和同帧骨骼，识别输入仍为 512×288。无人且关闭骨骼的时段持续更新高清图像。

专用验收 APK 还覆盖了 512×288 分路的 ORT CPU 回读，用来核对槽位租约。最终 60 秒窗口记录的 1532 个原生槽均在观察到 snapshot fence 完成后归还，最多同时有 3 个槽在等待回读，上限为 4。公开 CPU 模式沿用现有配置。

## 软件回归与设备范围

Android ARM64/API 26 Input 构建通过，主机 Input 回归 56/56，Android 动态导出和依赖集合与基线一致。Unity 2021.3.45f1 的 InputAdapterTests 25/25 与相机/分析纹理回归 1/1 通过。独立的 2022.3 编辑器相关 EditMode 93/93、Windows D3D11 PlayMode 3/3 和相机纹理/已绘制配对时序回归 1/1 通过。

一加机器上的测试覆盖共享的 MediaCodec/Vulkan RTSP 输入、NCNN Vulkan 后端和独立 CPU 回读路径。Rockchip Vulkan 驱动、RKNN 运行时、RK3588 持续吞吐和业务动作响应仍待 RK3588 实机验收。
