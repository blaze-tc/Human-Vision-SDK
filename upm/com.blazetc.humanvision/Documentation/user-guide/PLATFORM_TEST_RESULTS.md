# 平台测试效果文档

适用SDK `0.4.0-preview.4` / Input `0.1.0-preview.2`。本文只汇总SDK发布验证、SDK历史真机测量与新项目复测方法。[文档首页](README.md)

## 1. 怎样理解测试结果

| 标记 | 可以说明什么 |
| --- | --- |
| 安装/初始化通过 | 该环境能导入包并创建会话；不代表持续识别性能 |
| 自动验证通过 | 指定测试/构建/导入已覆盖该项；不能替代真机性能 |
| 测量有效、目标未达标 | 报告限定边界内统计有效，但未满足30FPS等要求 |
| 待验收/不覆盖 | 缺少该设备、能力或构建组合的证据 |

显示FPS、相机FPS、身体结果FPS、每个人有效完整关节点FPS是不同指标。容量8、一帧看到7人、创建32点数组都不能代替持续8人每人30FPS。

## 2. SDK 历史 Android 真机基线

以下是 SDK 统一示例 在 Snapdragon888 上的历史测量，**不是本次文档更新重新运行的测量**。报告分别绑定测试 APK/模型哈希；不能将它们直接归到安装版本相同但内容未比对的新 APK。

统计窗口固定为10秒预热后 `[10s,50s)` 的40秒，完整保留零身体/部分身体结果，不挑“最好的一段”。FPS为 Manager 收到的新完整结果快照数/40秒，完整快照不等于每人每关节全部有效。

限制：

- Camera为混合负载，不能写成单人或4人性能；RTSP容量8，实际并非连续8人。
- 年龄从本地发布开始，不是摄像头曝光/拍摄到屏幕显示延迟；RTSP流PTS不能直接与Unity单调时钟相减。
- RTSP在受控服务器/adb转发环境测试，不能证明任意远程IPC/公网/无线网络兼容与延迟。
- 历史 `inference_fps` 某些运行值为0，因此测量用实际结果序号/接收记录，没有用HUD该字段作为吞吐依据。
- 历史可见多人骨骼不证明所有点、ID连续性、真实手端点、持续跑跳精度。当前随包Profile禁用真实手部推理。
- HD测试前后电池温度快照不是持续热稳定证明。
- 低/中/高有模型合同与包验证，不存在同设备同条件完整三等级性能对比结论。

## 5. 新项目怎样复测

1. 记录设备CPU/GPU、系统、Unity版本、双包tag/lock hash、构建模式、EXE/APK与运行数据hash、实际Profile、质量、容量、区域、源编码/实际尺寸/FPS与镜像。
2. 按[新手引导](FIRST_INSTALL.md)先验证单人Camera，再分别验证Video/RTSP和1/2/4/6/8人。使用实际人数，不用容量替代。
3. 检查框与骨骼可见性；记录每个StableTrackId必需点的Valid/Confidence/观察时间，并测遮挡、出画面、换人、左右方向和ID连续性。
4. 配置固定后预热10秒，至少采集连续40秒完整窗口；另做长时间稳定性/热测试。期间切源/质量/区域时标记窗口失效，重新开始。
5. 在ResultUpdated边界采集，每个新的身体ResultSequence最多计一次；零身体/部分点结果也保留。Bodies复用，历史记录复制值，检查采集队列溢出/丢弃。
6. 计算源FPS、新完整结果FPS、每人有效完整FPS、年龄P50/P95、阶段耗时、掉点、ID变化和丢帧。有效完整点集合应先声明；显示采样/保持不能增加观察数。
7. Android测试权限拒绝、前后台、Vulkan失败、停止/重连；RTSP测试网络断开重连。Windows测试相机占用、文件缺失、目标机器上的独立构建。验证保存与重启。
8. 将同窗口录屏/截图、构建/配置hash、日志绑定。结论写通过/不通过/证据不足，并明确时钟与采集边界。

[Reader示例](examples/SdkSkeletonReader.cs)为约1Hz日志演示，不能直接充当无损全速性能采集器。严格性能采集应在回调复制每个新观察并记录溢出，避免逐帧Debug.Log干扰性能。

## 6. SDK统计字段的边界

`ResultSequence`用于身体序号去重，`SourceFrameId`用于结果来源，不同于显示帧号。某些启用独立手任务的配置可以在同一身体序号下发手更新，手观察应按独立关节时间判断。

`DetectionMs/PoseMs/TrackingMs`在Runtime模式映射预处理/推理/后处理，`ProcessedFrames`映射BodySequence；不要据V1旧字段名推断当前模型有独立检测阶段。`InferenceFps`历史部分运行值为0，不能据它替代实际结果接收测量。

本次更新只核对文档、SDK API和示例；没有新跑设备性能。当前可以说明发布安装闭包与历史测量可追溯，不能说明所有设备通过、连续8人每人30FPS或真实手点已验收。
